# LinkPeek

LinkPeek is a real-time webpage screenshot service that captures website snapshots, stores them, serves them, and keeps them fresh. A single HTTP GET API returns an image for a given target URI, designed for direct HTML embedding and scheduled captures.

- **Provider:** https://linkpeek.com/
- **Documentation:** https://linkpeek.com/docs
- **Base URL:** https://linkpeek.com/api/v1
- **Tags:** website screenshot, webpage snapshot, thumbnail generation, image-as-a-service, web capture, developer tools, SEO, marketing tooling
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** no
- **Confidence:** 90/100

## APIs

- **LinkPeek Website Screenshot API** — REST-style HTTP GET endpoint that accepts a target web page URI and returns a screenshot image. Supports size (e.g., size=original) and viewport (mobile/tablet) options. Designed for direct HTML embedding and scheduled captures. (`https://linkpeek.com/api/v1`)

> Public, self-serve REST/HTTP screenshot API at https://linkpeek.com/api/v1?uri=... returning an image; docs are prose/tutorial-based. Authentication is account/plan-based but the exact credentialing mechanism is not clearly documented; free thumbnail generator uses keyless GET. No machine-readable contract (no OpenAPI/AsyncAPI/GraphQL/Postman). No agent-native surfaces: no hosted or local MCP server, no llms.txt, no published agent skills.
