# LinkPeek

Website screenshot SaaS that captures, stores, serves, and refreshes webpage screenshots via a simple REST-style image API. Give it a target URL and it returns an image.

- **Provider:** https://linkpeek.com/
- **Documentation:** https://linkpeek.com/docs
- **Base URL:** https://linkpeek.com/api/v1
- **Tags:** Screenshot API, Web Capture, Rendering, Imaging API, Website Monitoring, Developer Tools, SaaS
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** no
- **Confidence:** 90/100

## APIs

- **LinkPeek Screenshot API** — REST-style HTTP/image API that returns a webpage screenshot for a given URL. GET request authenticated by apikey plus an MD5-signed token query parameter; supports uri, size, and viewport options. (`https://linkpeek.com/api/v1`)

> Public REST-style image API at https://linkpeek.com/api/v1, authenticated via apikey + MD5-signed token query parameters, self-serve signup at https://linkpeek.com/signup. No machine-readable contract (no OpenAPI/AsyncAPI/GraphQL/Postman) — only hand-written client code snippets in multiple languages. No agent-native surfaces: no hosted or local MCP server, no llms.txt, no published agent skills. Note: several unrelated projects share the 'linkpeek' name; this covers only linkpeek.com.
