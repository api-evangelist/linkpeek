# LinkPeek

LinkPeek.com is a real-time website screenshot service that captures, stores, serves, and refreshes webpage snapshots via a simple API-key-gated HTTP GET image API. Customers embed hotlinkable screenshots in websites, apps, blogs, and emails, with support for mobile/tablet viewports and pixel-level sizing.
