# LinkPeek

LinkPeek.com is a hosted real-time webpage screenshot service. Its GET-based image API captures, stores, serves, and refreshes website snapshots, supporting full-page/full-height capture, size/aspect-ratio cropping, and device emulation via query parameters. Also offers a free website thumbnail generator.

- **Provider:** https://linkpeek.com/
- **Documentation:** https://linkpeek.com/docs
- **Base URL:** https://linkpeek.com/api/v1

## APIs

- **LinkPeek Website Screenshot API** — GET-based, image-returning HTTP API for capturing website screenshots. Accepts a target URL plus option flags (size, viewport) and returns an image that can be hotlinked or fetched server-side. Account/plan-gated. (`https://linkpeek.com/api/v1`)
