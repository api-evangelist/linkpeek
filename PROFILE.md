# LinkPeek

LinkPeek is a fast real-time website screenshot service that captures, stores, serves, and auto-refreshes webpage snapshots on demand via a simple HTTP GET image API.

- **Provider:** https://linkpeek.com/
- **Documentation:** https://linkpeek.com/docs
- **Base URL:** https://linkpeek.com/api/v1
- **Tags:** Website Screenshots, Web Page Capture, Image Generation & Rendering, Web Scraping, Developer Tools, Media & Thumbnails
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** no
- **Confidence:** 85/100

## APIs

- **LinkPeek Screenshot API** — HTTP GET endpoint that returns a cached or freshly captured website screenshot image. Accepts a target URL plus options such as size and viewport (device emulation). Requires an account-issued API key on paid plans. (`https://linkpeek.com/api/v1`)

> LinkPeek exposes a single REST-style HTTP GET screenshot API at https://linkpeek.com/api/v1 (image response, API-key auth, paid). No machine-readable contract (OpenAPI/AsyncAPI/GraphQL/Postman) is published. No agent-native surfaces exist: no hosted or local MCP server, no llms.txt, and no published agent skills.
