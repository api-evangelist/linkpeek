# LinkPeek

Real-time website screenshot service that captures, stores, serves, and refreshes webpage snapshots via a simple GET-based image API. Give it a target URI and it returns a screenshot image.

- **Provider:** https://linkpeek.com/
- **Documentation:** https://linkpeek.com/docs
- **Base URL:** https://linkpeek.com/api/v1
- **Tags:** Website screenshots, Webpage snapshots, Web capture, Thumbnail generation, Website monitoring, Developer tools, Media & imaging API, SaaS
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** no
- **Confidence:** 85/100

## APIs

- **LinkPeek Screenshot API** — GET-based HTTP image API that returns a screenshot for any given web page URI. Embeddable directly in HTML via img/anchor tags. Supports request options such as size=original and viewport for mobile/tablet screenshots. (`https://linkpeek.com/api/v1`)

> Public REST/HTTP screenshot API reachable at https://linkpeek.com/api/v1?uri=[web page address], returning an image rather than JSON. Free evaluation via the Website Thumbnail Generator; production requires a paid plan with per-request metering (billing via Stripe). No machine-readable contract (no OpenAPI/AsyncAPI/GraphQL/Postman) was found. No agent-native surfaces: no hosted or local MCP server, no llms.txt, and no published agent skills. Auth is account/plan-based; an explicit per-request API-key parameter was not clearly documented publicly and should be confirmed in a logged-in dashboard.
