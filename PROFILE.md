# LinkPeek

Real-time website-screenshot service that captures, stores, serves, and periodically refreshes webpage screenshots. Send a target URL and receive an image; cached images return in milliseconds and fresh captures in seconds.

- **Provider:** https://linkpeek.com/
- **Documentation:** https://linkpeek.com/docs
- **Base URL:** https://linkpeek.com/api/v1

## APIs

- **Website Screenshot API** — REST-style HTTP GET image API. A call to /api/v1 with query parameters (uri, size, viewport) returns a screenshot image directly. Authenticated with an apikey plus an MD5 request-signature token; requires a paid account. (`https://linkpeek.com/api/v1`)
