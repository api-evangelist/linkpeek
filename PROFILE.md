# LinkPeek

Hosted real-time webpage screenshot service. Captures, caches, serves, and refreshes website snapshots via a simple signed REST API, returning images with pixel-level size control and viewport emulation.

- **Provider:** https://linkpeek.com/
- **Documentation:** https://linkpeek.com/docs

## APIs

- **LinkPeek Screenshot API** — Signed GET endpoint that returns a webpage screenshot. Auth is API-key plus an MD5 token computed from a shared secret, the target uri, and size. Supports uri, apikey, token, size, and viewport query parameters. (`https://linkpeek.com/api/v1`)
