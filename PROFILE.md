# LinkPeek

A real-time website screenshot / webpage-snapshot REST API that captures, stores, serves, and refreshes embeddable webpage screenshots with size, quality, and viewport controls.

## APIs

- **LinkPeek Screenshot API** — Single-endpoint REST/HTTP screenshot API that returns an image for a target URL. Authenticated with an apikey plus a secret-signed token; supports size, viewport, and full-page capture options. (`https://linkpeek.com/api/v1`)
