# LinkPeek

> A free, open-source URL-intelligence and developer-utility REST API. Turns any URL into a JSON
> link-preview card and any string into a QR code, plus DNS/WHOIS/SSL checks, security-header
> inspection, IP geolocation, and data-conversion helpers. The free tier needs no API key and is
> metered at 100 requests/day per IP; a $1/month Pro key lifts that to 50,000/day. The service is a
> Flask app self-hosted on Oracle Cloud Free Tier behind a raw-IP sslip.io hostname, MIT-licensed
> and self-hostable.
>
> Generated by API Evangelist from apis.yml and the artifacts in this repository — the provider
> publishes no llms.txt of its own (probed 2026-08-09: /llms.txt returned 404 on both hosts).

## APIs

- [LinkPeek API](https://147.15.103.217.sslip.io): REST API for URL intelligence, QR codes, DNS/WHOIS/SSL and developer utilities. 107 routes are registered live; 16 are documented in the published OpenAPI.
- [LinkPeek Screenshot API](https://linkpeek.com/docs): NOTE — a separate, unrelated company (LinkPeek.com, New London CT, screenshots since 2011) that shares the name. Its API is `https://linkpeek.com/api/v1` and is API-key + MD5-token authenticated.

## Key operations

- `GET /api/preview?url=` — link-preview JSON card
- `GET /api/qr?text=` — QR code PNG
- `GET /api/qrcode?text=` — QR code as base64 JSON
- `GET /api/batch?urls=` — up to 5 previews in one call
- `GET /api/extract?url=` — meta plus headings and links
- `GET /api/metadata-full?url=` — every meta tag
- `GET /api/meta-tag-parser?url=` — meta and link tag dump
- `GET /api/favicon-extractor?url=` / `GET /api/favicons?url=` — favicon discovery and proxying
- `GET /api/headers?url=` — response headers only
- `GET /api/og-image?title=` — 1200x630 placeholder OG image
- `GET /api/key?email=` — 14-day trial key
- `GET /api/subscribe?email=` — Pro key plus payment link
- `GET /api/status` / `GET /api/health` — discovery and health

## Conventions

- Auth: optional API key on the `key` query parameter (`ApiKeyAuth`). The free tier requires none.
- Rate limiting: per-IP daily quota; metered JSON responses carry a `quota` object (`plan`, `limit`, `used`, `remaining`, `reset_iso`); exhaustion returns `429`.
- Errors: a flat JSON envelope `{error, url, detail, max, got}` — not RFC 9457 problem+json.
- Every documented operation is `GET`; there is no idempotency-key contract and no outbound webhook surface.
- CORS is open (`Access-Control-Allow-Origin: *`).
